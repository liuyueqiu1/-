# 事实判断体验

预试体验版，供「大学生对生成式人工智能错误信息的识别与核验提示效果」准备阶段试用。这不是学校官网，也不是正式研究招募。材料版本 **v0.2**，十二条陈述的顺序和正误键固定。

页面用简体中文。作答只留在当前浏览器里，不会上传到研究数据库。

## 本地运行

需要 Node.js 22。

```bash
npm ci
npm run dev
```

开发服务器监听 `127.0.0.1:4179`。这个地址只在运行命令的那台电脑上有效，不是已经部署给其他人的线上网址。

生产构建：

```bash
npm run build
npm start
```

`npm start` 同样只在本机的 `127.0.0.1:4179` 提供页面。要把页面给别人打开，需要你自己准备的托管，并接受该主机通常会保留访问日志。本仓库没有配置托管账号，也没有已验证的公开预览地址。

## 测试

```bash
npm run test:unit
npm run test:e2e
```

端到端测试会自行启动开发服务器，并覆盖：拒绝参加、未勾选同意、分组在刷新后保持、三组提示各自只出现一次、未答完不能锁定、选择「无法判断」会清空信心、十二题完成后的计分、正误颠倒时不会把两类分数对调、跳过回顾、JSON/CSV 导出、清除本地草稿，以及约 375px 与桌面宽度。

## 体验流程

1. 阅读说明。确认年满 18 周岁并自愿开始，或者选择暂不参加。暂不参加不会分配分组。
2. 开始时抽取一次 A/B/C，写入本地草稿。刷新、返回和锁定之后都不重抽。三组题目、顺序、选项和检索许可相同。
3. 逐题判断：正确、有误、无法判断。只有「正确」或「有误」需要 1–5 的信心。
4. 复核。十二条都作答后才能锁定。锁定后不能再改判断和信心。
5. 可选回顾：四道背景题，以及每题是否查阅过。可以全部跳过。
6. 查看事实说明和来源链接，并可由你点击导出 JSON 或 CSV。

A 组提示是「请阅读短文本，判断其中的关键事实。」B、C 在这句后面追加句子。各组都写明可以使用公开网页检索。页面不会同时展示三种提示。

## 数据放在哪里

键名是 `factcheck-demo-v0.2`，使用浏览器 `localStorage`。里面有尝试编号、分组、同意时间、每题判断、信心、可选回顾和粗略的前台停留时间。

- 尝试编号是随机生成的，不是设备指纹。
- 时间标成 `Asia/Shanghai`，格式如 `2026-11-16T08:30:00+08:00`。中国标准时间全年为 UTC+8，这里没有根据定位猜测时区。
- 停留时间只在页面前台时累计，不是反应时，也不能解释成认知过程。
- 导出的 CSV 使用 UTF-8 BOM。以 `=`、`+`、`-`、`@`、制表符或回车开头的单元格会加上前导单引号，降低表格软件把内容当成公式执行的风险。这不是加密。
- 背景题空着会计为 `skip`，不影响分数。
- 「清除本机草稿」只删除这份本地记录。已经下载的文件还在设备上，页面无法远程删除。
- 如果通过网站服务器访问，服务器仍可能保留普通访问日志。不能据此说绝对匿名。

计分在体验者这一层计算：

- 判断相符 / 12：准确陈述选「正确」，或有误陈述选「有误」。
- 正确陈述接受 / 6：只统计六条准确陈述里选了「正确」的数量。
- 错误陈述识别 / 6：只统计六条有误陈述里选了「有误」的数量。把准确陈述判成「有误」不会算进这一项。
- 无法判断单独列出。

答案和来源写在前端代码 `lib/instrument.ts` 里，完成后才显示。这不是防作弊考试，不适合对抗性的正式施测。

## v0.2 相对初稿的处理

- 背景题和逐题查阅自陈移到锁定之后、事实说明之前。
- 组别提示改为同一基线句，B、C 只追加句子，不提示错误是怎样放进题目的。
- Q4 题干只保留正式名称 `ununoctium`，不并列元素符号。
- Q5 只问罗塞塔石碑的收藏机构，不问是否正在展出。
- Q6 保持「秦始皇兵马俑的发现始于1974年」，不写成所有俑坑都在该年发现。
- Q8 保留「相符」，不写成当天已经最终确认该粒子的一切性质。
- 阿波罗 11 号一题保留协调世界时 1969 年 7 月 20 日，以及对应的北京时间 7 月 21 日。

## 原型和正式研究差在哪里

这个仓库是可运行的试用页面，不是可以直接招募的正式研究系统。正式使用之前至少还需要：

- 研究者身份、联系方式和可执行的退出办法
- 学校或伦理审查要求的知情同意、保存期限和数据管理
- 服务器端的访问控制、传输与存储安全
- 不把答案键放在每个参与者都能看到的前端代码里
- 可核验的随机化实施方案和样本量设计，而不是浏览器里抽一次并承认本地数据可以改
- 把查阅行为做成客观记录时，要单独设计，而不是只用事后自陈

这些题目涉及事实知识和查阅，不是经过验证的、可以概括全部现实场景中人工智能错误识别能力的量表。
